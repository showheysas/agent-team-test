# トレイルシーカー納車遅延 調査レポート

ディーラーから「部品調達不足により納車が1ヶ月遅延」との連絡を受け、エージェントチーム機能で多角的に原因調査を実施した結果をまとめたものです。

## 構成

| # | レポート | 視点 |
|---|---------|------|
| 01 | [サプライチェーン分析](reports/01_supply_chain_analysis.md) | 上流の部品・物流ボトルネック |
| 02 | [ディーラー視点分析](reports/02_dealer_perspective.md) | 「部品調達不足」の裏に隠れる真因 |
| 03 | [製造・生産工程分析](reports/03_manufacturing_analysis.md) | 工場・ラインのボトルネック |
| 04 | [顧客アクションプラン](reports/04_customer_action_plan.md) | 補償交渉と意思決定 |

## 主要な仮説(暫定)

各エージェントの分析を統合すると、有力な真因は以下のいずれか(複合の可能性大):

1. **半導体/ECU の調達遅延** ― ADAS搭載グレードで発生しやすい(01)
2. **配車優先順位の劣後 + ロット繰越** ― 1ヶ月という長さから示唆される(02)
3. **オフロード車特有のオプション(4WD・特殊サスペンション)による特注扱い** ― 製造ラインで個別対応が必要(03予定)
4. **海上輸送ルートの紅海迂回などによる物流遅延** ― 14日前後の追加リードタイム(01)

## 次のアクション(優先度順)

- **VIN採番の有無をディーラーに確認** → 真因がメーカー側かディーラー側か二分類できる(02)
- **生産ロット番号/生産週の確認** → リコール・品質問題に紐づくサインがないかチェック
- **契約書の納期遅延条項と代車提供義務を確認**(04)
- **メーカー直接窓口に同じ説明で照合**(02)

詳細は各レポートを参照してください。
