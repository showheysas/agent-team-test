## 結論(Web実調査ベース)

### 真因はディーラー固有問題ではなく、構造的なもの

> **トレイルシーカーの納車遅延は、あなた個人やこのディーラー固有の問題ではなく、車種全体に広く発生している現象です。**

#### 根拠

1. **同様の遅延報告が価格.com BBSで多数確認**(07)
   - 4月契約・黒色は6月以降にずれ込み
   - 5月契約は9〜10月生産予定
   - **「4月注文 → 7月中旬〜8月生産」はこのパターンの中央値に近い**

2. **量産開始がごく最近**(05・06)
   - 2026年2月4日 群馬製作所 矢島工場で量産開始(スバル初の自社生産BEV)
   - 月販計画 **わずか250台**、初年度国内 **3,000台**目標
   - 受注殺到が複数ソースで確認されている

3. **公式リコール・生産停止アナウンスは無し**(06・07)
   - NHTSAリコール登録なし
   - スバル公式の生産停止アナウンスもなし
   - 「部品調達不足」はディーラーレベルの説明であり、コーポレートレベルではない

4. **背景の構造的要因**(06)
   - スバル2026年通期営業益90%減(2026/5/15発表)、自社開発EV延期表明
   - ただしトヨタ共同開発4モデル(Solterra/Uncharted/**Trailseeker**/Getaway)はスケジュール維持と明言
   - トランプ15%関税で物流再編中
   - AI需要によるメモリ半導体(eMMC/DRAM)世界的ひっ迫
   - **部品の約70%をトヨタ経由で調達** → トヨタ側の供給制約に連動しやすい構造

### 「部品調達不足」の解釈

ディーラーの説明は**部分的に正しい**(メモリ・希土類などの業界全体の逼迫は事実)が、より大きな主因は:

> **量産立ち上げ初期の歩留まり・能力制約 + 受注殺到 + トヨタ経由部材の制約**

つまり構造的・一時的な問題であり、リコールやStop-Shipのような深刻な品質問題の兆候は**現時点で確認できません**。

### 1ヶ月遅延の妥当性

業界水準で **「想定範囲内」**。エスカレーション(契約解除や強い補償要求)が正当化されるのは**3ヶ月超の遅延**になった場合です。

## あなたが今すぐ取るべきアクション

### 優先度高

1. **生産確定週(Production Week)とVIN採番有無をディーラーに確認**
   - 「7月中旬〜8月生産」が確定なのか努力目標なのかを明確に
   - 確定なら遅延はこれ以上広がらない可能性が高い

2. **同色・同グレード受注者の状況を価格.com BBS等で照合**
   - 該当スレッド: `SortID=26477525` 「トレイルシーカー契約」
   - 自分の納期がコホート中央値からズレていないか確認

### 優先度中

3. **契約書の納期遅延条項を再確認**(04参照)
   - 通常 BEV の量産立ち上げ初期では遅延条項は緩い設計のはず
   - 万一3ヶ月超になった場合の解約条件・補償条件を予め把握

4. **メーカー(SUBARUコール 0120-052-215)に直接照会**
   - ディーラー説明と公式情報を照合
   - 「部品調達不足」の具体的内容を尋ねる(明確な回答は期待しにくいが、リコール隠しの有無を間接的に確認できる)

### 優先度低(現状では不要)

5. キャンセル・別車種への切替検討 — 現時点では構造的要因が明確で、3ヶ月以内に解消される可能性が高いため**まだ早い**
